📊 E-Commerce Sales Analysis Dashboard (Power BI)

An interactive Power BI dashboard built to analyze an E-Commerce sales dataset and uncover insights about sales performance, customer behavior, product categories, and regional trends.

This project demonstrates how Power BI can transform raw business data into interactive visual insights for decision-making.

📌 Project Overview

The purpose of this project is to analyze an e-commerce sales dataset and create a business intelligence dashboard that helps understand:

Overall sales performance

Profitability by product category

Regional sales distribution

Customer segment behavior

Impact of discounts on profit

Using Power BI visualization tools and DAX calculations, the project converts raw data into meaningful insights.

🎯 Business Questions Answered

The dashboard answers important business questions:

✔ What are the total sales, profit, and quantity sold?
✔ Which product categories generate the most revenue?
✔ Which regions contribute the highest sales?
✔ Which customer segments are most profitable?
✔ How do discounts affect profit margins?

📂 Dataset Description

The dataset contains detailed e-commerce transaction data including order details, customer information, product categories, and financial metrics.

🧹 Data Preparation

Before building the dashboard, the dataset was prepared by:

✔ Removing duplicate records
✔ Checking column data types
✔ Cleaning categorical values
✔ Formatting date fields
✔ Verifying numeric columns (Sales, Profit, Discount)

This ensured the dataset was ready for accurate visualization and analysis.

🔍 Key Insights

From the dashboard analysis:

📌 Technology category generates the highest sales

📌 Furniture category shows lower profit margins due to heavy discounts

📌 Consumer segment contributes the largest portion of revenue

📌 Certain regions and cities dominate overall sales performance

💡 Business Recommendations

Based on the insights:

✔ Reduce excessive discounts on low-margin products

✔ Focus marketing on high-performing regions

✔ Promote high-margin technology products

✔ Monitor loss-making products and pricing strategies
